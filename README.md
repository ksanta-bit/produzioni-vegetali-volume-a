# Produzioni Vegetali - Volume A

Mappe concettuali interattive originali per lo studio di UD 5 e UD 12.

Le scansioni private del manuale sono fonti di studio locali e non sono incluse in questo progetto pubblico.

Le pagine includono una funzione di lettura vocale facoltativa: selezionando il testo compare il comando `Ascolta selezione`. La sintesi usa una voce italiana disponibile sul dispositivo e non invia il testo a servizi esterni.
